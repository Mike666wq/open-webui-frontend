# 录音转文档与聊天布局

入口：**笔记 → 录音转文档**，或右上角的**转写任务**。录音功能复用后端「管理设置 → 音频」中的服务端云 ASR 配置，本次不绑定千问、豆包或其他厂商。

## 使用流程

- 上传课堂／会议录音；默认普通话。页面显示有效大小与时长限制（默认500MB、2小时，受更严格的全局上传限制约束）。上传期间保持页面打开，提交成功后可以离开，后台任务不会随页面关闭而停止。
- 选择任务查看阶段及已完成分段。失败、取消或服务中断后可以手动重试；上次请求可能已经计费。更换 ASR 配置会从头转写，不能混合旧模型的结果。
- 完成后生成普通笔记，可以在此编辑保存，也可进入原有笔记编辑器。任务另存 ASR 原文快照，支持分别导出原文和编辑后的文档为 TXT／MD。
- ASR 返回时间戳时可点击回听；返回说话人编号时可手工改名。跨音频分段不自动认定身份相同。模型只返回文字时正常使用，不生成虚假的时间戳或说话人。
- 原音频默认保留；任务停止并结束在途请求后，可单独永久删除。文档仍然保留，但无法回听或重试音频。
- 选择已有服务端文字模型，手动生成课堂笔记或会议纪要；结果另存为关联笔记。使用已保存的转写笔记，文字模型可能另行计费，失败不影响转写原文。
- 选择当前文档和目标知识库，保存文字快照；编辑后再次点击更新同一份快照。录音不随文字共享，目的知识库必须允许写入。

完成后的文档区按三步排列：**编辑并保存笔记 → 生成独立整理稿 → 加入或更新知识库**。
转写原文已自动保存为私有笔记；标题与正文的修改会标为未保存，离开或切换文档时提示保存风险。
整理稿以转写原文笔记为材料，另存新笔记；选择整理稿后，知识库操作针对这份整理稿。
知识库区显示当前文档与目标库；保存成功后记录该副本的内容指纹，内容相同时禁用重复提交。
修改标题或正文后，需要手动更新知识库副本；更新会沿用原文件并同步文件名。
失败提示分别显示在整理稿或知识库区域。请求结果不确定时，请先检查目标库；多接口写入并非原子事务，不会自动重试。

任务状态轮询暂时失败只显示局部提示，后台任务可能仍在继续；状态读取恢复后提示自动消失。
模型目录故障与具体转写任务状态分开显示。播放器加载失败也不会改变转写任务或笔记状态。

删除原录音只删除音频，不会自动删除任务卡片。原录音删除且处理已停止后，可另行确认
**删除任务记录**；这会永久删除任务及 ASR 快照，已生成的笔记和知识库文档保留。
关联笔记被删除或不可访问时，页面会单独提示，不会把它当成转写失败或持续重试该笔记。
若误删笔记，可在「资源与存储」恢复后点击「重新检查笔记」。

管理员可在页面展开「录音限制与 ASR 返回格式」调整上限。默认JSON；仅在服务文档明确支持时启用Verbose／Diarized JSON。通用 `/audio/transcriptions` 与厂商专用异步协议不是同一接口，不能仅修改模型名实现适配。真实模型选定后仍需做课堂样本识别与费用验收。

录音详情仅对上传者开放；分享笔记不会自动分享音频。上传者可从笔记顶部的「录音与转写详情」回到原任务。

## 聊天布局

输入框宽度约束放在明确的居中内层，外层保持完整可用宽度。消息与输入框以扣除侧栏后的聊天区域为中心，保留各自宽度设置；消息和Markdown祖先允许收缩，长内容在自身区域滚动。

## 验证

- `npm run test:frontend -- --run` 包含转写导出的时间戳、说话人名称、完整原文降级测试。
- 现有真实浏览器 CI 增加1280／1440／1920桌面侧栏开关居中检查，继续验证375／393／430手机、背景和设置，并使用模拟API验证上传、编辑转写、生成独立整理稿、知识库新增及更新快照。
- 浏览器测试使用独立数据和模拟模型，不证明任何真实ASR的识别准确率，也不声称实际安卓设备已验收。
- 发布顺序保持前端验证、前端发布与Android构建，再由后端锁定对应前端产物并构建镜像。

前后端分阶段发布时，新入口受后端 `enable_recording_documents` 能力标识控制；旧后端不会显示尚不可用的功能入口。
