# Reading and page layout

Knowledge and notes use a near-opaque reading surface in both themes, independently of wallpaper detail. The small Layout control can hide the top toolbar and navigation independently. Its restore action remains accessible while both are hidden; choices are stored in the current browser.

Notes have an on-demand heading outline. It follows the current document, supports nested headings and scrolls without changing the content. Notes and knowledge file previews have full-window reading; Escape exits. The same editor/viewer stays mounted, the background application becomes inert and keyboard focus returns to the launch control when leaving full-window mode.

Tests use synthetic notes and do not modify production documents or invoke paid models.
